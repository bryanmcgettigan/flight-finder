# ✈️ Flight Finder  
A simple and fast web app to help you find the **cheapest flights** between your chosen destinations.  

![Flight Finder Example](./46a57180-19bf-43b8-8c2b-5ce27e9cab1d.png)  
*Example: Searching for flights from Dublin to Lisbon*  

---

## 🚀 Features  
- 🔍 Search for flights between any two cities  
- 💸 Find the cheapest available flights  
- ⚡ Fast and responsive interface built with **React**  
- 🌐 Backend powered by **Node.js**  
- 📡 Real-time flight data using the [FlightAPI](https://www.flightapi.io/)  

---

## 🛠️ Tech Stack  
- **Frontend:** React  
- **Backend:** Node.js + Express  
- **API:** [FlightAPI.io](https://www.flightapi.io/)
